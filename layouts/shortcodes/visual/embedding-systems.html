1. Weight Tying (Shared Input & Output Matrix)

-524M Params (1.05 GB FP16)

Instead of allocating a separate output classifier matrix to project the final hidden state {{ transform.ToMath `\mathbf{h}_L \in \mathbb{R}^d` $m }} back to vocabulary logits, decoders reuse the transposed input embedding table (Press & Wolf 2017). At {{ transform.ToMath `V = 128\text{k}, d = 4096` $m }}, this cuts over 1 GB of model weights.

{{ transform.ToMath `\mathbf{W}_{\mathrm{head}} = \mathbf{W}_E^T, \quad \mathbf{z} = \mathbf{h}_L \mathbf{W}_E^T \in \mathbb{R}^V` $m }}

2. Embedding Variance Scaling

Unit Variance O(1)

Embedding weights initialized with variance {{ transform.ToMath `\sigma^2 = 1/d` $m }} produce small coordinate magnitudes of order {{ transform.ToMath `\mathcal{O}(1/\sqrt{d})` $m }}. Multiplying the gathered row by {{ transform.ToMath `\sqrt{d}` $m }} restores unit variance before adding positional signals.

{{ transform.ToMath `\mathbf{h}_0 = \sqrt{d} \cdot \mathbf{W}_E[t_i] + \mathbf{p}_i` $m }}

3. Pre-RMSNorm Stabilization

Single-Pass Reduction

Modern Transformers (LLaMA 3, Mistral, Gemma) replace LayerNorm with Root Mean Square Normalization (Zhang & Sennrich 2019). Dropping mean-centering eliminates one full reduction pass across dimension {{ transform.ToMath `d` $m }}, reducing GPU memory bandwidth overhead.

{{ transform.ToMath `\operatorname{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{\frac{1}{d}\sum_{j=1}^d x_j^2 + \epsilon}} \odot \boldsymbol{\gamma}` $m }}
