Multimodal Unification: Late-Fusion Vision Adapter vs. Native Early-Fusion (Transfusion / Chameleon)

Figure 1 (Adapter vs. Native Multimodality): (1) Late-fusion models bolt a frozen vision encoder onto a text LLM via a 2D pixel-shuffle projector, enabling visual understanding but no native image/audio generation. (2) Early-fusion architectures (Chameleon, Transfusion) ingest interleaved text, image, and audio tokens into a single Transformer from layer 1, using QK-LayerNorm to prevent cross-modal logit explosion.
